# Support

## Getting help

- Issues: open a bug report or feature request via
  `.github/ISSUE_TEMPLATE/`.
- Docs: start with `README.md`, then `docs/adr/` and
  `services/agents/README.md`.
- Maintainer: Aniruddha Adak — see commit history for contact.

## Response expectations

- Bug reports: triaged within one week.
- Security reports: acknowledged within 72 hours (see `SECURITY.md`).
- Hackathon period: expect faster, async-first replies.

## Useful commands

```bash
bun install
bun dev
bunx vitest run
cd services/agents && pytest test_app.py -v
```
